# 产品说明

Bifurcation 为不超过 10 位用户共享代理节点提供自托管管理能力。控制平面采用单实例部署，节点运行 Linux systemd 服务。

本文件描述现行实现。2026-09-14 的下一版设计增量见 [多订阅与 Kumo 一致性 PRD](PRD-SUBSCRIPTIONS.md)：支持每个用户多条独立订阅、完整客户端模板、节点组绑定及可选 JSON Patch，并统一 Table/Dialog。其中多订阅、完整模板编辑和节点属性筛选已实现；可选 JSON Patch、原生核心隔离校验及部分高级流程仍为设计规格。

## 角色和凭据

空数据库首次打开首页自动进入创建管理员界面，设置用户名与后备密码后直接登录，无需初始化命令或激活链接。只要数据库已有任意账号，初始化入口即关闭，包括已有待激活或禁用账号的情况。初始管理员可在账号设置中补加 Passkey；后续用户仍由管理员创建并通过一次性链接激活。

管理员负责创建和恢复账号、管理节点、发布配置、调整额度和执行维护。普通用户查看自己的用量、订阅和账号设置。管理员也有独立的个人视图。

账号通过一次性激活流程设置后备密码，并可同时绑定 Passkey。不支持或无法使用 Passkey 时，可仅设置后备密码，之后在账号设置中添加 Passkey。密码可以独立登录，不要求长度或字符组合，仅须非空；登录凭据变更要求近期认证。恢复可选择仅设置密码，仍替换旧登录凭据并撤销旧会话，保留 API Key。不能禁用或降级最后一个启用的管理员。

API Key 只在创建时展示明文，长期有效，使用账号当前角色和启用状态。机器 Token 由管理员长期查看和复制，绑定指定安装实例。订阅链接与代理凭据可以分别重置：重置订阅不会撤销已导入客户端中的代理凭据。

## 节点和代理

节点 daemon 主动连接面板，通过持续的任务流接收通知。浏览器关闭不影响任务、计量或额度协调。

sing-box 作为 Go 库内嵌于 daemon。节点提供 Trojan 和 Hysteria2，支持 TCP/UDP。管理员配置监听地址、端口和证书，可编辑基础 JSON，并在发布前查看与受管理字段合并的最终配置。证书可来自上传 PEM、节点文件路径或节点自助 ACME 签发。用户身份、代理凭据和受管入站由平台生成；不允许基础配置绕过这些字段。

节点配置通过机器详情进入独立编辑页，支持直接访问和刷新。基础 JSON 为节点端补充配置：空对象使用默认日志和直连出站，自定义同名顶层字段整项替换默认值，不进行深度合并。页面提供字段限制与日志示例，编辑后须重新生成预览才能发布。

配置发布使用版本检查和请求幂等键。切换失败时恢复上一份基础配置，同时保留已接收的最新授权限制。无法安全恢复时报告失败，不能重新开放已撤销的凭据。

## 客户端订阅

每个账号可创建最多 20 条命名订阅，例如 PC 与手机；它们共享账号授权节点和代理凭据，但分别保存完整客户端模板、节点组筛选、草稿、发布版本与独立链接。创建和复制先生成草稿，预览通过后显式发布；保存无效 JSON 草稿不会改变已发布结果。单条链接可独立重置、暂停、恢复或删除。

管理员通过机器信息维护地区和自定义标签。默认模板参考 `E:\Tool\xx\config\config.json` 的 DNS、广告过滤、国内直连、AI/游戏分流、TUN 和缓存结构，去除真实服务器、密码及个人应用例外。通用组使用全部可用节点，AI/游戏组分别筛选 `ai`/`game` 标签。各订阅可修改地区、标签、协议、指定/排除机器及固定组成员，不能通过自动组间接超出筛选范围。属性不是授权，所有筛选均限制于账号当前可用节点。

代理出口使用稳定机器 ID 与协议组成的 `bfc_` tag，服务器地址、TLS 和凭据在每次拉取时根据当前快照生成。无匹配节点、引用错误、循环或过期预览会阻断发布/下载，不使用旧结果兜底。当前预览检查 JSON、绑定及出口引用图，不等于原生核心解析、远程规则集可达性或特定客户端兼容性验证。

已有用户的原链接按原字节迁移为「默认订阅」，未显式发布新模板前保持原有生成行为。默认模板在新建时复制，后续代码升级不覆盖用户保存的模板。重置代理凭据影响所有订阅，暂停或删除链接不撤销已导入客户端的连接凭据。

## 用量与额度

用户按机器和时间范围查看上下行用量；管理员查看全局和用户×机器汇总。计费字节来自代理连接，主机网卡累计字节单独展示。

月度额度按上海自然月计算，上下行合计。额度为空表示不限量，0 表示无接入额度。手工禁用和额度阻断分别处理；提高额度或进入新月份不会解除手工禁用。

节点执行授权变更存在传播时间。界面展示目标与实际应用状态，离线节点不能被描述为已完成撤销。计量保留估算和不完整标记，未知字节不补造；趋势峰值表示分钟平均峰值。

## 维护

机器详情按概览、用量、操作记录、接入与维护组织；进行中的任务跨标签可见。列表可按名称、地址、地区、标签搜索并筛选连接状态。概览集中展示最近上报的资源、管理连接和配置状态，失联数据标记为最近值。

在线维护要求标准安装器管理的 Linux systemd 安装；普通容器部署需更新镜像并重建容器，面板显示具体原因。正确管理的 systemd 容器仍按相同安装检查判断，不仅凭容器标识禁用。旧 daemon 未提供原因时显示待确认，不猜测部署方式。

daemon 制品包含确定版本的核心。升级先校验平台、摘要和本地兼容性，再由独立更新器切换。成功需要新进程本地就绪及重新连接后的独立状态报告。只有网络不可达不触发反复回滚。

升级和重启会中断代理连接。正常关闭先停止核心并结算尾部 I/O，再持久化计量。崩溃造成的未观察内存计数无法恢复，记录为缺口。

卸载由独立 helper 完成停止、补报、确认和所属文件清理。面板移除记录是独立操作，不等同于本机卸载。

## 运行范围

面板以 Docker Compose 单实例运行，持久化 SQLite 和应用密钥。节点使用 Linux amd64/arm64。客户端配置面向 sing-box；第三方客户端的导入和协议兼容性需分别验证。

系统不提供公开注册、独立 Go 控制平面、集群协调或无损热升级。备份恢复的授权与计量边界见 [备份与恢复](BACKUP-AND-RESTORE.md)。
