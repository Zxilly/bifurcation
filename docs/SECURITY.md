# 安全模型

## 信任边界

管理员被信任管理节点代理配置、证书、机器 Token 和更新。普通用户只能访问自身资源。机器凭据只授权对应安装实例的协议操作，不能代替用户 API Key；订阅 token 只提供个人只读配置。

生产入口使用 HTTPS。面板以非 root 容器用户运行，仅向反向代理开放回环端口。daemon 以 root 管理本机服务和文件，节点主机及管理员账号属于受信任边界。

## 凭据

- 后备密码使用 Argon2id；Passkey 验证 challenge、origin、RP ID 和账号归属。
- Session、API Key、一次性流程按摘要保存和验证。账号角色或状态变化立即影响后续授权。
- 机器 Token、订阅 token、代理凭据及敏感配置使用固定应用密钥认证加密。
- API Key 明文仅首次返回；机器 Token 按产品要求可由管理员反复查看。管理员诊断不脱敏，应限制管理权限。
- 账号恢复替换登录凭据并撤销会话，API Key 的撤销是独立操作。

应用密钥必须与数据库分开受控保存并纳入恢复流程。日志、截图、测试产物和错误报告不得公开 Token、API Key 或证书私钥。

## 授权与执行

所有传输入口执行鉴权和资源归属校验，不能依赖导航可见性。Cookie 写请求校验 origin，登录凭据修改使用近期会话认证。耗时请求体解析后重新检查当前权限。

配置的授权版本下限持久化且不能回退。恢复旧基础配置不恢复已撤销的访问。离线节点在收到新策略前可能继续旧配置，界面必须展示实际同步状态。

更新任务只能使用受控制品和匹配的 SHA-256。下载、命令输出和协议消息有界；系统命令使用参数列表，节点不接受任意远程 shell 任务。安装、回滚和卸载保留必要的身份与确认状态。

## 数据恢复

SQLite 一致快照不自动恢复快照之后的业务事实。旧备份可能缺少已确认用量或近期撤销；恢复后需要核对授权与高水位。不可恢复的数据标记缺口，不能猜测或补造。

详细操作见 [备份与恢复](BACKUP-AND-RESTORE.md)。回归与隔离服务测试见 [开发指南](DEVELOPMENT.md)。
